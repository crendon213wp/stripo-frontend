Important first step

You must create a Stripo.email account before using this application. Without an account, the Stripo editor and this framework will not work.

Before the first click

Set the stage
in four steps.

Everything runs locally. You bring the Stripo credentials; the framework takes care of the handoff.

You will need Node.js 18+, npm, Git, a Plugin ID, and a Secret Key.
01

Download the project

Clone the repository , then move into the master_stripo_file directory.

02

Make private settings

Copy .env.example to .env and add your Stripo Plugin ID and Secret Key.

03

Install dependencies

Run npm install once from the project directory.

04

Start the app

Run npm start, then open http://localhost:3000.
